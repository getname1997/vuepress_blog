​	RSI=100×A/(A+B)（A为周期内上涨幅度总和，B为下跌幅度总和） 

​	（70以上超买、30以下超卖）

### **IC（信息系数）**

 	因子值与未来收益的相关性，>0 表示正向预测能力

- **IC 均值**： 大于0表示因子有效（因子值越高，未来收益越高）。通常**绝对值 > 0.03** 被认为有一定预测性，> 0.05 就很不错。
- **IC 标准差**： 衡量IC的稳定性。标准差越小，因子越稳定。
- **ICIR （信息比率）**： `IC均值 / IC标准差`。这是衡量因子稳定性和综合表现的最重要指标之一。**ICIR > 0.5** 通常认为因子质量较高。
- **IC 衰减**： 观察IC随着持有期（1天， 2天， … 30天）的推移如何变化。一个好的因子，IC通常在短期（1-5天）最高，然后逐渐衰减到0。这有助于确定最佳**持有周期**。

####  **换手率**   太高不好

衡量因子的**稳定性**或**交易成本**。指从一个调仓周期到下一个周期，投资组合中需要更换的股票比例。

- **分位数换手率**： 通常**第一组（Top）和最后一组（Bottom）的换手率最高**，因为要维持在极端分组。
- **高换手率**（如 > 30%）意味着因子变化快，交易成本（佣金、冲击成本）会严重侵蚀收益，可能不适合作为低频策略（如月度调仓）的核心因子。

​		

#### **因子自相关性**

​		衡量因子值自身的**持续性**

- 高自相关性意味着因子值在时间序列上变化缓慢。这对于**降低换手率**是好事。例如，市值因子自相关性极高，几乎不需要频繁调仓。
- 低自相关性意味着因子值变化快，可能是动量或反转类因子。



#### **长短期收益率**

​		分别计算在调仓后的第1天、第2天、…、第N天的平均收益。常用`mean_return_by_quantile`函数的热力图展示。
