## isinstance

类型判断

a = ''dssdds

isinstance(a,'str')  // true

```python

# 检查单个类型
isinstance(*10, int)         # True
isins*tance(*"hello", str)    # True
isins*tance(*10, str)         # False
# 检查继承关系 (假设有类 A 和它的子类 B)
class A:
    pass
class B(A):
    pass
b_instance = B()
isinstance(b_instance, B)   # True
isinstance(b_instance, A)   # True (因为 B 是 A 的子类)

# 检查元组类型
isinstance(10, (int, float, str)) # True
isinstance("hello", (int, float, str)) # True

```





## 递归

~~~python
def factorial(n):
    # 基线条件：0! = 1, 1! = 1
    if n <= 1:
        return 1
    # 递归条件：n! = n * (n-1)!
    return n * factorial(n - 1)

print(factorial(5))  # 120

~~~
